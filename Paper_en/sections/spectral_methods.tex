\section{Spectral methods}
\label{sec:spectral}

To obtain a gradual measure, we represent each rule as a numerical vector (\emph{embedding}) derived from its transition graph, so that the distance between vectors works as a similarity index.

\subsection{Eigenvalues}

We compute the eigenvalues of the adjacency matrix of the transition graph, sort them and use them as the \emph{embedding} of the rule; two rules are compared through the cosine distance between their vectors, which measures how different their spectra are. This method has two limitations:
\begin{itemize}
    \item \textbf{Blindness to transients}: each connected component is made of trees that lead to a cycle, and since the trees only contribute zero eigenvalues, the spectrum depends only on the attractors. ECA rules 0 and 8 have a single attractor, reached in at most 1 and 2 steps, respectively, so their eigenvalues are identical.
    \item \textbf{Domain dependence}: the number of eigenvalues equals the number of nodes $N = |\mathcal{S}|^n$, so only rules with the same number of states and the same space size can be compared.
\end{itemize}

In the full graph, from $n = 8$ on we obtain between 67 and 74 classes (Figure~\ref{fig:all-methods}). In the quotient, from $n = 12$ on we obtain between 56 and 63, and combining it with the full graph adds no classes (77 in both cases, Table~\ref{tab:methods}). The groups \{0,8\}, \{1,19\}, \{2,24,46\}, \{4,12\}, \{18,126\}, \{36,72\}, \{128,136\}, \{130,152\}, \{132,140\} and \{162,168\} have the same spectrum for every size computed: they have the same cycles and differ only in their transients.

\subsection{Spectral moments}

To remove the domain dependence we propose to use spectral moments: instead of the full spectrum, for each step $k = 1, \dots, K$ we measure the proportion of configurations that return to themselves after $k$ steps,
\[
  m_k = \frac{|\{x \in \mathcal{C} : F^k(x) = x\}|}{N}.
\]
The length of the vector does not depend on the number of nodes but on the window $K$, so rules with different numbers of states, neighbors or spaces can be compared; $K$ must be chosen so that it captures the relevant cycles of both graphs. Since $m_k$ depends only on the eigenvalues, this method inherits the blindness to transients. With $K = 60$ we obtain a maximum of 74 classes. In the full graph, increasing $K$ stabilizes the number of classes as $n$ grows, while in the quotient $K$ has little influence, since the cycles are shorter.

\subsection{Spectral moments with attractor mass}
\label{subsec:attractor_mass}

To distinguish rules such as 0 and 8, we need to measure, besides the attractors, how strongly they attract the other configurations, that is, how many configurations reach each attractor and in how many steps. The idea is that each cycle is still activated every $p$ steps, as in the spectral moments, but at each activation we also add the configurations that have already reached it. Using the height $h(x)$ and the period $p(x)$ of each configuration, we define
\[
  \tilde{m}_k = \frac{|\{x \in \mathcal{C} : p(x) \mid k \ \text{ and } \ h(x) \le k - p(x)\}|}{N}, \quad k = 1, \dots, K.
\]
That is, a configuration counts at step $k$ if its attractor is activated at that step and the configuration had already reached it before the previous activation: cycle nodes ($h = 0$) count from the first activation ($k = p$), nodes with $1 \le h \le p$ from the second ($k = 2p$), and so on. Since every periodic configuration satisfies the condition when $p \mid k$, the vector decomposes as $\tilde{m}_k = m_k + t_k$, where $m_k$ is the spectral moment and $t_k$ is the proportion of transient configurations that count at step $k$. Thus, the new vector extends the spectral moments with the information of the basins and keeps their length $K$ independent of the domain, with the limitation that a cycle with $p > K$ is never activated.

For example, with 5 cells ($N = 32$), rule 0 sends every configuration to zero in one step ($h \le 1$), whereas in rule 8 each block of ones leaves an isolated 1 that disappears in the next step ($h \le 2$); of the 32 configurations, 12 reach zero in at most one step. Their vectors, $\tilde{m}^{(0)} = \tfrac{1}{32}(1, 32, 32, \dots)$ and $\tilde{m}^{(8)} = \tfrac{1}{32}(1, 12, 32, \dots)$, are no longer equal, even though their spectral moments are.

With the attractor mass the number of classes increases considerably (Figure~\ref{fig:am-classes}): in the full graph, with $K = 60$ and $n \ge 6$ we obtain between 79 and 83 classes, and the quotient reaches up to 80. Rules 0 and 8 are separated for every $n \ge 3$, and combining $n = 3$ and $n = 6$ gives 86 classes with the full graph. Only two pairs remain together: \{1,19\}, whose exact heights are different but fall in the same interval of $p$ steps, and \{4,12\}, which coincide in the distribution of height and period and differ only in the shape of the trees. The quotient, on the other hand, groups the rules that differ by a composition with the translation (\{15,51\}, \{170,204\}, \{4,12,34\}, \ldots) and only reaches 81 classes. Using the full graph and the quotient on the same size gives 87 classes with $n = 6, 10, 12, 14, 18, 22, 24$ and $26$.
